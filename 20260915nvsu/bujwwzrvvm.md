# 通过宫高和腹围怎么计算胎儿体重

通过宫高和腹围怎么计算胎儿体重更新时间:2022-12-28

孕妇朋友在孕期中，需要及时了解胎儿的体重，这样才能知道胎儿发育是否正常，如果需要及时咨询医生。一般来说，可以通过宫高腹围来计算胎儿的体重，那么，宫高腹围标准计算胎儿体重的方法是怎样的呢？接下来，请看详细的介绍。

1.用宫高腹围算胎儿体重的方法

胎儿体重(克) = -2686.60 + 171.48×腹围

胎儿体重(克) = 2900 + 0.3×宫底高×腰围

胎儿体重(克) = -5168.32 + 100.97×头围 + 110.86×腹围+ 143.09×股骨长 + 331.43×胎儿腿部皮下脂肪厚度

以上方法为估算值，并不代表婴儿出生的实际体重。预测胎儿体重的目的在于要及早发现胎儿发育上存在的问题。一般来说，出生时的实际体重与预测体重会有正负10%-15%的误差。比如，出生体重4000克，其误差范围会为400克。也就是说，宝宝体重越大，误差范围也就越大。

2.测量宫高的方法

让孕妇排尿后，平卧于床上，用软尺测量耻骨联合上缘中点至宫底的距离。一般从20周开始，每4周测量1次；怀孕28-35周每2周测量一次；怀孕36周后每周测量一次。测量结果画在妊娠图上，以观察胎儿发育与孕周是否相符。

3.测量腹围的方法

腹围与胎宝宝的大小关系非常密切。在孕晚期通过测量宫高和腹围，还可以估计胎儿的体重。胎儿体重估计（g）=子宫长度（cm）×腹围（cm）＋200（g）。如果连续2周宫高腹围没有变化，孕妈咪最好去医院检查一下。
