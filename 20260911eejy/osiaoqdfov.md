# 成果初现！关注银屑病规范化诊疗

> 更新时间：2026-09-11 (UTC+8)

我国银屑病患者治疗预后的队列研究

日前，北京大学第一医院国家皮肤与免疫疾病临床医学研究中心（以下简称中心）团队在JAMA Network Open（IF 13.3）上发表论著，首次应用疾病严重度等级间转移概率（transition probability）的方法对银屑病患者治疗后的短期预后进行分析，直观全面地展示了银屑病的预后。论文通讯作者是北京大学第一医院副院长、中心执行主任李航教授。

该研究依托于中心发起的“银屑病规范化诊疗中心项目”，建立了全国多中心银屑病队列，采用2020年8月～2021年12月的16523例队列数据进行分析。队列启动于2020年8月，是中心启动的第一个全国协作临床研究项目。项目目标是开展多中心临床登记研究，用真实世界临床大数据总结中国银屑病病例诊疗规范；探索共建、共享、共赢的新机制，真正实现全国协作；建设专病医联体，推动医疗均质化。虽然受到新冠疫情的影响，但是该项目得到了全国同道的积极响应，发展迅速。截止至2023年2月，共计339家三级医院加入中心协作网，覆盖了全国30个省级行政区、128个城市，迄今收集病例数量突破10万例。

指导开展全国多中心的临床研究是中心的科研重点工作，为了推动全国协作可持续性，中心一方面通过完善质控和量化评估体系，保障数据量质齐升；另一方面，鼓励参与单位通过申报课题获得数据开展研究，第一批开放课题申报单位达到29家，共34个课题按照1：20（中心提供的数据量是录入量的20倍）获得大数据。2022年开放了第二批开放课题申报。

中心以高标准、高水平协调推进协作网各单位的临床研究工作，经过几年的数据收集与挖掘，已经产出了初步成果，令人欣喜。第一批课题已经有6篇论文发表或被接收，其中3篇被SCI收录，本文开头提到的发表于JAMA Network Open论文就是其中之一；还有3篇刊于中文核心期刊。文章内容不仅限于常规临床研究，还包括中医和中西医结合视角的论文。值得一提的是，在产出的成果中，有两篇是项目牵头单位北京大学第一医院发表的，其余4篇都由其它项目单位发表。

我国银屑病患者诊疗现状的横断面研究（北京大学第一医院）

吸烟与疾病严重度的关联性研究

同济大学上海皮肤病医院团队（通讯作者：史玉玲教授）对2020年8月–2021年9月的4529例数据进行横断面关联分析，发现吸烟年限和每日吸烟量均和银屑病严重度呈正相关；且相比于非吸烟患者，有吸烟史的患者无论有无戒烟，银屑病皮损加重的风险均增加，这为我国未来的银屑病患者教育提供了参考。该成果现已被Frontiers in Medicine接收。

对生物制剂治疗抵抗的顽固皮损部位分析

北京积水潭医院（通讯作者：潘婧教授）纳入73例经≥24周足量、规范化生物制剂治疗的银屑病患者，对生物制剂抵抗的常见顽固性皮损部位进行总结，并对肿瘤坏死因子抑制剂及白细胞介素17抑制剂在顽固部位皮疹的清除效果方面进行比较，为我国未来的难治部位银屑病提供治疗参考。文章发表于中华国家皮肤与免疫疾病临床医学研究中心杂志。

中药治疗银屑病疗效的研究

齐齐哈尔市中医医院团队（通讯作者：孙莹教授）选取了中心80例银屑病患者进行队列研究，发现常规治疗联合中药凉血解毒汤口服及中药药浴治疗疗效显著优于单纯常规治疗。该研究已被《医药与卫生》接收。

发病年龄与临床特点、生活质量的关联研究

河南省人民医院团队（通讯作者：刘鸿伟教授）对中心录入的6134例银屑病患者进行了横断面分析，发现早发银屑病患者生活质量受损更易受影响，而晚发银屑病患者更易出现系统性合并症。该研究已发表于《中国皮肤性病学杂志》。

“当一个全国协作的大数据库被多个单位应用并产生成果，就说明该数据库有实用价值了，而且大大增加了数据库可持续发展的可能性。”在刚刚结束的中心年会上，中心执行主任李航教授表示。期待由国家皮肤与免疫疾病临床医学研究中心启动的全国多中心协作项目有更多成果产出，也期待借助这个项目能够建立起高效高质的全国协作机制，助力诊疗水平均质化。
